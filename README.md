# Desktop Notepad Application

A lightweight desktop notepad application built with Python and Tkinter for quick text editing and file management.

## Features

- **Text Editing:** Clean interface for writing and editing text with word wrapping.
- **File Management:** Open existing `.txt` files and save new text documents easily.
- **Error Handling:** Built-in dialog alerts for file read/write issues.

## Tech Stack

- **Language:** Python 3.x
- **GUI Framework:** Tkinter (standard Python library)

## How to Run

1. Make sure you have **Python 3** installed on your system.
2. Clone or download this repository.
3. Open your terminal/command prompt and navigate to the project directory.
4. Run the application:

```bash
python main.py
